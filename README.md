# Billion Squares Website — billionsquares.com

A premium, responsive static website that can be deployed directly on Vercel with no build step.

## GitHub + Vercel
1. Create a new GitHub repository, for example `billion-squares-website`.
2. Upload **the contents of this folder** to the repository root.
3. Open Vercel → **Add New → Project** → Import the GitHub repository.
4. Framework Preset: **Other** (Vercel can also auto-detect the static site).
5. Build Command: leave empty.
6. Output Directory: leave empty / project root.
7. Click **Deploy**.
8. After deployment, Vercel → Project → Settings → Domains.
9. Add `billionsquares.com` and `www.billionsquares.com`.
10. Vercel will show the exact A/CNAME DNS records. Add those records in GoDaddy DNS.

## Before public launch
- Add official Billion Squares mobile number, WhatsApp and email to `contact.html` and the footer.
- Connect `#leadForm` to the CRM/email/WhatsApp workflow.
- Verify all approvals, project facts, prices and RERA/legal statements before publishing.
- Add Google Analytics / Google Tag Manager, Meta Pixel and Google Search Console.
